We are using herdr, first thing you have to do it open a new pane to the right of this pane, and start claude with model 5.x.

You are the coding agent pane and that new pane is the reviewer pane.

- In the new pane you will start the command herdr-review.
- In this pane (coding agent) you will run the herdr-feedback command

Then your setup is complete and the commands will take over here.
