## Overview

The **Payment Worker** drives money movement. It requests charges from the external [[system|stripe]] via [[event|payment-requested]] and refunds via [[event|refund-requested]], then consumes the [[event|payment-succeeded]] and [[event|payment-failed]] events Stripe returns and records the outcome in the [[container|payment-database]]. It also refunds customers for returned items when the Fulfilment domain publishes [[event|return-received]].

### Responsibilities

| Area | Description |
|------|-------------|
| Charging | Requests charges via [[event\|payment-requested]]. |
| Refunds | Requests refunds via [[event\|refund-requested]]. |
| Returns | Consumes [[event\|return-received]] and requests a refund for the returned items. |
| Outcomes | Consumes [[event\|payment-succeeded]] / [[event\|payment-failed]] and records them. |
| Persistence | Reads from and writes to the [[container\|payment-database]]. |
