## 1. Publish a customer-requested cancellation

Publish a cancellation made by the customer from their account before fulfilment started.

### Payload details

- `orderId` identifies the cancelled order; `customerId` identifies the customer who cancelled it.
- `reason` is `CUSTOMER_REQUESTED`.
- `cancelledAt` records when the cancellation happened in UTC.

### Using this example

Use this to check that consumers release any reserved inventory and refund any captured payment for the order.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderCancelled schema. The package names and publish methods are illustrative.

</Column>

import { EventsClient } from "@acme/events";

const client = new EventsClient({
  apiKey: process.env.ACME_API_KEY,

  orderId: "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  customerId: "6f9619ff-8b86-d011-b42d-00cf4fc964ff",
  reason: "CUSTOMER_REQUESTED",
  cancelledAt: "2026-09-11T10:15:00Z",
});

## 2. Publish an out-of-stock cancellation

Publish a cancellation made by the system because inventory could not be reserved. No customer initiated it, so `customerId` is omitted.

### Payload details

- `reason` is `OUT_OF_STOCK`.
- `customerId` is absent, because the cancellation was not initiated by a customer.
- `orderId` and `cancelledAt` are present as in every cancellation.

<Admonition type="warning" title="Optional field">
  `customerId` is not present on system-initiated cancellations. Look the customer up by `orderId` instead of assuming the field exists.
</Admonition>

<Steps>
  <Step title="Release inventory">Consumers holding reservations for this order should release them.</Step>
  <Step title="Notify the customer">Send the out-of-stock notification using the order's contact details.</Step>
</Steps>

### Using this example

Use this to check that consumers handle a missing `customerId` and follow the steps above.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderCancelled schema. The package names and publish methods are illustrative.

</Column>
