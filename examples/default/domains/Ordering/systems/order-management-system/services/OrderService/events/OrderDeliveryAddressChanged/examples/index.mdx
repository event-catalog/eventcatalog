## 1. Publish a customer address correction

Publish the corrected delivery address after the customer fixed a mistyped postcode from their account. Fulfilment and carrier integrations use the new address for dispatch.

### Payload details

- `addressRevision` is `2`, the first change after the original address.
- `previousPostalCode` is the postcode being replaced.
- `deliveryAddress` is the full new address, including the optional `line2`.
- `changedBy` identifies the customer who made the change.

### Using this example

Use this to check that carrier integrations replace the whole address, and ignore any update whose `addressRevision` is lower than the one they already hold.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderDeliveryAddressChanged schema. The package names and publish methods are illustrative.

```javascript publish-order-delivery-address-changed.js
import { EventsClient } from '@acme/events';

const client = new EventsClient({
  apiKey: process.env.ACME_API_KEY,
});

const event = {
  orderId: '4e9d1b7a-8c2f-4a6e-b3d5-1f7c9e2a4b68',
  addressRevision: 2,
  previousPostalCode: 'M4 1HQ',
  deliveryAddress: {
    recipientName: 'Sam Patel',
    line1: '27 Oldham Street',
    line2: 'Flat 3',
    city: 'Manchester',
    postalCode: 'M1 1JQ',
    countryCode: 'GB',
  },
  changedBy: 'customer:6f9619ff-8b86-d011-b42d-00cf4fc964ff',
  changedAt: '2026-09-12T09:58:10Z',
};

await client.publish('OrderDeliveryAddressChanged', event);
```

## 2. Publish a second change by a support agent

Publish a new address for an Irish order after the customer phoned support to send it to their office instead. This is the second time the address has changed.

### Payload details

- `addressRevision` is `3`.
- `deliveryAddress` has no `line2`, and `countryCode` is `IE` with an Eircode in `postalCode`.
- `changedBy` identifies the support agent who made the change.

### Using this example

Use this to check that consumers accept addresses without `line2` and handle non-UK postcode formats.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderDeliveryAddressChanged schema. The package names and publish methods are illustrative.

</Column>
