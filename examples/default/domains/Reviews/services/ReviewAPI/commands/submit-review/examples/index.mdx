## 1. Submit a five-star review with a title

A customer who bought the classic white T-shirt leaves a full review from their order history page. The storefront sends this command to the Review API, which stores the review and publishes `ReviewSubmitted`.

### Payload details

- `reviewId` is generated by the client, so a retried request does not create a duplicate review.
- `productId` is `prod_tshirt_classic_white` and `customerId` is `cust_4821`.
- `rating` is `5`, the top of the 1 to 5 star range.
- `title` (optional, max 120 characters) and `body` (max 5,000 characters) are both set.
- `submittedAt` is the UTC time the customer pressed submit.

### Using this example

Check that the Review API accepts the command, stores the review as pending moderation and publishes `ReviewSubmitted` with the same `reviewId`.

The examples use a **fictional Acme Events SDK** to send a payload matching the SubmitReview schema. The package names and send methods are illustrative.

</Column>

```javascript send-submit-review.js
import { EventsClient } from '@acme/events';

const client = new EventsClient({

  customerId: 'cust_4821',
  rating: 5,
  title: 'Perfect everyday tee',
```

```python send_submit_review.py
import os

    "customerId": "cust_4821",

    "title": "Perfect everyday tee",
    "body": "Soft, thick cotton and it kept its shape after washing.",
    "submittedAt": "2026-09-14T18:22:10Z",
}

```

```java SendSubmitReview.java
import com.acme.events.EventsClient;

    var client = new EventsClient(

    );

    var command = Map.of(
      "reviewId", "3f2b8c1e-5d4a-4e7b-9a1c-6b2d8e4f7a90",
      "productId", "prod_tshirt_classic_white",
      "customerId", "cust_4821",
      "rating", 5,
      "title", "Perfect everyday tee",
      "body", "Soft, thick cotton and it kept its shape after washing.",
      "submittedAt", "2026-09-14T18:22:10Z"
    );

    client.send("SubmitReview", command);
  }
}
```

## 2. Submit a low rating without a title

A customer returns an oversized hoodie and leaves a short two-star review from the mobile app, skipping the optional title.

### Payload details

- Only the required fields are sent; `title` is omitted.
- `productId` is `prod_hoodie_oversized_grey` and `customerId` is `cust_1057`.
- `rating` is `2`, so this review will pull the product's average rating down once it is published.
- `body` explains the sizing problem in the customer's own words.

### Using this example

Use this payload to test that a review without a `title` is accepted and that low ratings go through the same moderation path as high ones.

The examples use a **fictional Acme Events SDK** to send a payload matching the SubmitReview schema. The package names and send methods are illustrative.
