## Overview

The **Notification Service** is the single place Acme Inc talks to customers outside the storefront. It consumes events from other domains, looks up the customer's channel choices in [[container|notification-preferences]], sends the message and publishes [[event|customer-notified]].

### Notifications sent

| Event | Customer message |
|-------|------------------|
| [[event\|order-confirmed]] | Order confirmation with summary and delivery estimate. |
| [[event\|shipment-delivered]] | Delivery confirmation. |
| [[event\|payment-failed]] | Ask the customer to update their payment method. |
| [[event\|refund-processed]] | Refund confirmation. |
| [[event\|review-published]] | Let the reviewer know their review is live. |
| [[event\|loyalty-points-earned]] | New points balance. |
| [[event\|return-approved]] | Return label and drop-off instructions. |
