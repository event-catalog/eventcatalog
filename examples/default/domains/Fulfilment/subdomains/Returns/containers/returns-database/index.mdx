### What is this?

The **Returns Database** stores every return request. The [[service|returns-api]] writes new requests, and the [[service|returns-processor]] reads them and records approval and receipt.

### What does it store?

- **Returns** — one row per return: order, customer, reason and status (`requested`, `approved`, `received`).
- **Return items** — SKUs, quantities and inspected condition.
