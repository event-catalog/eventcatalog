  - name: orderLineId
    type: UUID
    required: true

    references: order-line

    referencesIdentifier: orderLineId
  - name: quantity
    type: integer
    required: true
    description: How many units are being returned.
  - name: reason
    type: string
    required: true
    description: Why the customer is returning the items.
    enum:
      - damaged
      - wrong-item
      - no-longer-needed
      - not-as-described
  - name: status
    type: string
    required: true
    description: Return lifecycle state.
    enum:
      - requested
      - approved
      - received
      - refunded
      - rejected
  - name: refundId
    type: UUID
    required: false
    description: Refund issued once the return is received.
    references: refund
    relationType: settledBy
    referencesIdentifier: refundId
  - name: requestedAt
    type: datetime
    required: true
    description: When the customer asked for the return.

## Overview

Return requests belong to the Returns System. A request starts with [[event|return-requested]], moves on with [[event|return-approved]] and [[event|return-received]], and ends with a refund from Payments.
