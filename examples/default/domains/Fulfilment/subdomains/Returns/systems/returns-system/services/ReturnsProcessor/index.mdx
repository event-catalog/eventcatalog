## Overview

The **Returns Processor** consumes [[event|return-requested]], checks the returns window and item eligibility, and publishes [[event|return-approved]]. When the warehouse scans the returned parcel it publishes [[event|return-received]], which Payments uses to refund the customer and Inventory uses to restock.

### Responsibilities

| Area | Description |
|------|-------------|
| Approval | Applies the returns policy and emits [[event\|return-approved]]. |
| Receipt | Confirms returned items arrived and emits [[event\|return-received]]. |
| Persistence | Reads from and writes to the [[container\|returns-database]]. |
