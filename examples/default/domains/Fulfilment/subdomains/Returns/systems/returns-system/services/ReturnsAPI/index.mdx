## Overview

The **Returns API** receives [[command|request-return]] from customers, stores the request in the [[container|returns-database]] and publishes [[event|return-requested]] for the [[service|returns-processor]].

### Responsibilities

| Area | Description |
|------|-------------|
| Intake | Handles [[command\|request-return]] and validates the order and items. |
| Persistence | Writes new return requests to the [[container\|returns-database]]. |
| Event publishing | Emits [[event\|return-requested]]. |
