## Overview

The Fulfilment domain owns this endpoint. Other domains send [[command|reserve-inventory]] to it to hold stock, and the [[service|inventory-service]] handles each command. During checkout, the [[service|checkout-orchestrator]] in the Ordering domain sends commands to it.
