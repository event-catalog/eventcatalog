feat(core): a search-first homepage and a quieter, more consistent look across the catalog. The default homepage opens on a search box with "Browse by type" beneath it, and search shows a preview of the highlighted result. Docs, schema, resource, team, user, trigger and custom docs pages get breadcrumbs (every step a link) and one type scale for titles, summaries and content. The Discover filters and tables, the header search, row actions menus and tags are restyled, and the ubiquitous language page is now an A–Z glossary. Search finds every resource (systems, decision records, agents, teams and users were missing), matches the words you type in any order, and treats `OrderCreated`, `order-created` and `Order Created` as the same name.
