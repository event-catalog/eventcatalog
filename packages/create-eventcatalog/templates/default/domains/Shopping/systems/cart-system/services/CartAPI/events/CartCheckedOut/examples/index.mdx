## 1. Publish a single-item checkout

A customer checks out a cart with two T-shirts and no voucher. The Cart API publishes `CartCheckedOut`, and downstream systems use it to create the order and take payment.

### Payload details

- `eventId` and `occurredAt` identify this event and when the checkout happened (UTC).
- `items` holds one line: 2 T-shirts at a `unitPrice` of 2,000 pence each.
- `subtotal` and `discount` are omitted because no discount applied.
- `currency` is `GBP`, so all amounts are in pence.

The total is **2 × 2,000 = 4,000 pence (£40.00)**.

### Using this example

Check that the order created from this event has one line and a total of 4,000 pence, and that a missing `discount` is treated as zero.

The examples use a **fictional Acme Events SDK** to publish a payload matching the CartCheckedOut schema. The package names and publish methods are illustrative.

```typescript publish-cart-checked-out.ts
import { EventsClient } from '@acme/events';

  items: [
    {
      productId: '0e8f4b2a-7c1d-4f3e-9a5b-6d2c8e1f7a93',
      quantity: 2,
      unitPrice: 2000,
    },
  ],
  total: 4000,
  currency: 'GBP',
};

await client.publish('CartCheckedOut', event);
```

## 2. Publish a multi-item checkout with a discount

A customer checks out T-shirts, a hoodie and a cap with the `AUTUMN10` voucher. The event carries the subtotal, the discount and the final total so consumers do not need to reprice the cart.

### Payload details

- `items` has three lines: 2 T-shirts at 2,000, 1 hoodie at 4,500 and 1 cap at 1,500 pence.
- `subtotal` is the total before discounts.
- `discount` is the 10% voucher saving.
- `total` is `subtotal` minus `discount`.

The subtotal is **4,000 + 4,500 + 1,500 = 10,000 pence (£100.00)**, the discount is **1,000 pence (£10.00)** and the total is **9,000 pence (£90.00)**.

### Using this example

Check that the payment is taken for 9,000 pence, not the subtotal, and that the order has three lines.

The examples use a **fictional Acme Events SDK** to publish a payload matching the CartCheckedOut schema. The package names and publish methods are illustrative.
