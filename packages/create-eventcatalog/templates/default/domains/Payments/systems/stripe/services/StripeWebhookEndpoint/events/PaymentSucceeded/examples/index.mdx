## 1. Confirm a card charge with a Stripe reference

Stripe charges the card for the T-shirt and cap order. The StripeWebhookEndpoint publishes `PaymentSucceeded` and the PaymentWorker records the payment as succeeded.

### Payload details

- `paymentId` and `orderId` match the original `PaymentRequested` event.
- `amount` and `currency` are what Stripe actually charged, in pence.
- `processorReference` is Stripe's charge ID, kept for reconciliation and refunds.

The customer was charged **4,298 pence (£42.98)**.

### Using this example

Consumers should check that `amount` and `currency` match the requested charge before marking the payment as succeeded.

The examples use a **fictional Acme Events SDK** to publish a payload matching the PaymentSucceeded schema. The package names and publish methods are illustrative.

```typescript publish-payment-succeeded.ts
import { EventsClient } from '@acme/events';
import type { PaymentSucceeded } from './schemas/payment-succeeded';

const client = new EventsClient({
  apiKey: process.env.ACME_API_KEY!,
});

const event: PaymentSucceeded = {
  paymentId: '586e57ab-77a9-406a-945d-4619c76a582e',
  orderId: '971b5a4b-6885-405c-899b-5e0f428016c1',
  amount: 4298,
  currency: 'GBP',
  processorReference: 'ch_3PqL8x2eZvKYlo2C1a9bR4tD',
  succeededAt: '2026-09-11T08:12:52Z',
};

await client.publish('PaymentSucceeded', event);
```


```java PublishPaymentSucceeded.java
import com.acme.events.EventsClient;

      System.getenv("ACME_API_KEY")

    var event = Map.of(

      "amount", 4298,
      "currency", "GBP",
      "processorReference", "ch_3PqL8x2eZvKYlo2C1a9bR4tD",
      "succeededAt", "2026-09-11T08:12:52Z"
    );

    client.publish("PaymentSucceeded", event);
  }
}
```

## 2. Confirm a charge without a processor reference

Stripe confirms the guest hoodie payment. The webhook arrives without a charge ID, so only the required fields are published.

### Payload details

- `processorReference` is optional and omitted here.
- `amount` is three hoodies at €54.99 each, in cents.
- `currency` is `EUR`.

The customer was charged **16,497 cents (€164.97)**.

### Using this example

Use this payload to check that the PaymentWorker records the payment even when `processorReference` is missing.

The examples use a **fictional Acme Events SDK** to publish a payload matching the PaymentSucceeded schema. The package names and publish methods are illustrative.
