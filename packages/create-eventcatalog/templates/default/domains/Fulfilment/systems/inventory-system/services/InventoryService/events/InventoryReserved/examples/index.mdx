## 1. Publish a reservation for a multi-item order

The Inventory Service publishes this event when it holds stock for every item in an order. The checkout saga in the Ordering domain consumes it and continues placing the order.

### Payload details

- `reservationId` is the ID to use later in `ReleaseInventory`.
- `orderId` and `cartId` link the reservation to the order and the cart it came from.
- `items` holds 2 T-shirts and 1 cap, each by `productId` and `quantity`.
- `reservedAt` is the UTC time the stock was held.

In total, **3 units** are reserved across 2 products.

### Using this example

The checkout saga should move on to payment for this order. Tests can check that both line items are reserved in full.

The examples use a **fictional Acme Events SDK** to publish a payload matching the InventoryReserved schema. The package names and publish methods are illustrative.

```typescript publish-inventory-reserved.ts
import { EventsClient } from '@acme/events';
import type { InventoryReserved } from './schemas/inventory-reserved';

const client = new EventsClient({
  apiKey: process.env.ACME_API_KEY!,
});

const event: InventoryReserved = {
  reservationId: '4e9a1c7d-6b2f-4d8e-9c3a-7f5b0d1e2a86',
  orderId: '3f2b8c1e-7a4d-4e9b-9c21-5d8e6f0a1b27',
  cartId: '7a1e5c9b-3f8d-4b2e-a6c4-9d0f1b7e3a58',
  items: [
    {
      productId: '0b8e3d5f-9c2a-4f1e-b7d6-4a2c8e0f3b95',
      quantity: 2,
    },
    {
      productId: '6c1f9a4e-3d7b-4a2c-8f5e-9b0d2c7a1e38',
      quantity: 1,
    },
  ],
  reservedAt: '2026-09-14T08:12:45Z',
};

await client.publish('InventoryReserved', event);
```

          "quantity", 1

    client.publish("InventoryReserved", event);
  }

## 2. Publish a reservation for a cart

Stock can be held for a cart before the order exists. The event then links to the cart only and holds a single hoodie.

### Payload details

- `cartId` is set and `orderId` is omitted because no order has been created yet.
- `items` holds 1 hoodie.
- `reservationId`, `items` and `reservedAt` are the required fields.

### Using this example

Use this payload to check that consumers match a reservation by `cartId` when `orderId` is missing.

The examples use a **fictional Acme Events SDK** to publish a payload matching the InventoryReserved schema. The package names and publish methods are illustrative.

</Column>
