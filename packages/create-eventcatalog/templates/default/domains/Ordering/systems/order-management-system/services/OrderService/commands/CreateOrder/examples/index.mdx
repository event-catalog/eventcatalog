## 1. Create a multi-item order with its payment authorisation

Stock is reserved and payment is authorised for two T-shirts and a cap. As the final step of the checkout saga, the Checkout Orchestrator sends this command to the Order Service.

### Payload details

- `cartId` and `customerId` link the order to the checked-out cart and the customer.
- `items` has 2 lines: 2 × Classic White T-shirt at 1,999 pence and 1 × Logo Cap at 1,499 pence. `unitPrice` is per unit, in minor units.
- `total` is the sum of `quantity` × `unitPrice` across all lines.
- `currency` is `GBP`.
- `paymentAuthorizationId` references the hold placed by `AuthorizePayment`, so the funds can be captured.

The total is **3,998 + 1,499 = 5,497 pence (£54.97)**.

### Using this example

The Order Service should store both lines, check that `total` equals the sum of the lines, and publish `OrderCreated` with a total of 5,497 `GBP`.

The examples use a **fictional Acme Events SDK** to send a payload matching the CreateOrder schema. The package names and send methods are illustrative.

    {
      productId: '5e8f2a1b-3c4d-4e5f-8a6b-7c8d9e0f1a2b',
      quantity: 2,
      unitPrice: 1999,
    },
    {
      productId: '6f9a3b2c-4d5e-4f6a-9b7c-8d9e0f1a2b3c',

      unitPrice: 1499,
    },
  ],

## 2. Create a single-item euro order

A customer in Ireland buys one hoodie priced in euros. The command carries only the required fields and leaves out `paymentAuthorizationId`.

### Payload details

- `items` has one line: 1 × Heavyweight Hoodie at 5,799 cents.
- `total` equals that single line.
- `currency` is `EUR`, so `unitPrice` and `total` are in cents.
- `paymentAuthorizationId` is optional and omitted here.

The total is **5,799 cents (€57.99)**.

### Using this example

Use this to check that the Order Service creates an order without a `paymentAuthorizationId` and keeps the `EUR` currency on the resulting `OrderCreated` event.

The examples use a **fictional Acme Events SDK** to send a payload matching the CreateOrder schema. The package names and send methods are illustrative.
