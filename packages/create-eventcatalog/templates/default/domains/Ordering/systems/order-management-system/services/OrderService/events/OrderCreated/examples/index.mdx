## 1. Publish a new UK order

The Order Service has handled `CreateOrder` for two T-shirts and a cap. It publishes this event so fulfilment can start and the customer gets a confirmation email.

### Payload details

- `orderId` is the new order's ID, generated by the Order Service.
- `customerId` identifies who placed the order.
- `total` is in pence: 2 × 1,999 + 1 × 1,499.
- `currency` is `GBP`.
- `createdAt` is the ISO-8601 UTC time the order was stored.

The total is **5,497 pence (£54.97)**.

### Using this example

Consumers should start fulfilment and show £54.97 in the confirmation email, converting `total` from minor units.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderCreated schema. The package names and publish methods are illustrative.

</Column>

```typescript publish-order-created.ts
import { EventsClient } from '@acme/events';
import type { OrderCreated } from './schemas/order-created';

const client = new EventsClient({
  apiKey: process.env.ACME_API_KEY!,
});

const event: OrderCreated = {
  orderId: '4c7e9a2b-1d3f-4b5a-8e6c-2f9d0a1b3c5e',

  total: 5497,
  currency: 'GBP',
  createdAt: '2026-09-11T08:12:45Z',
};

await client.publish('OrderCreated', event);
```

## 2. Publish a new euro order

A customer in Ireland orders one hoodie priced in euros. The event has the same shape, but amounts are in euro cents.

### Payload details

- `orderId` and `customerId` identify the order and the customer.
- `total` is in cents: 1 × 5,799 for the hoodie.
- `currency` is `EUR`.
- `createdAt` is the ISO-8601 UTC time the order was stored.

The total is **5,799 cents (€57.99)**.

### Using this example

Use this to check that consumers format `total` with the event's `currency` and do not assume pounds.

The examples use a **fictional Acme Events SDK** to publish a payload matching the OrderCreated schema. The package names and publish methods are illustrative.
